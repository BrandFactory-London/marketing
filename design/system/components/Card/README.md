Cards group one object: a client, a post, a batch or a settings section.

- Classes: `bfm-card`; add `bfm-card-interactive` when the whole card opens something. Title in `bfm-card-title`, metadata in `bfm-card-meta`.
- Cards sit on `surface-50` with `space-6` padding and `space-6` gaps between them.
- The consumer provides the title, metadata and any badge or actions. Put a status badge top-right and actions bottom-right.
- Do not nest cards. Inside a card, separate groups with space, not borders.
