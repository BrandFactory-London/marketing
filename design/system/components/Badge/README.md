Badges show the status of a post, batch, pack or publish, always with the status word.

- Classes: `bfm-badge` plus one tone: `bfm-badge-neutral` (Draft), `bfm-badge-brand` (Spec ready, Writing, Checking), `bfm-badge-warning` (Needs review), `bfm-badge-success` (Approved, Published), `bfm-badge-danger` (Failed).
- Use only the fixed status words listed in the README; never invent new ones per screen.
- The consumer provides the word. The dot is drawn by the badge in the text colour.
